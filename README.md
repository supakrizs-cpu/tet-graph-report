# กราฟรายงาน TET

HTML ไฟล์เดียว: อัปโหลด Excel → ตาราง + กราฟรายวัน/สรุปปี → คัดลอกรูปวางใน LINE

- **ใช้งานจริง (หลัก):** https://tet-graph-report.supakrizs.workers.dev — ล็อกอินบัญชีเดียวกับ Sale Order Tracker · ข้อมูลบน Supabase (Cloudflare deploy `public/`)
- ไฟล์ `dist/TET-กราฟรายงาน.html` ใช้ในเครื่องได้ — ซิงก์ Supabase ชุดเดียวกัน และใช้ตอนไม่มีเน็ตได้ (ส่งขึ้นเองเมื่อเน็ตกลับมา)
- **จะแก้ต่อ อ่าน `HANDOFF.md` ก่อน** (กฎสั้นสำหรับ AI อยู่ใน `AGENTS.md`)
- **repo นี้ไม่มีข้อมูลจริง ห้าม commit ไฟล์ Excel/JSON ข้อมูล**

## แก้ไขโปรแกรม
1. แก้ไฟล์ใน `src/` (`app.js`, `styles.css`, `index.template.html`, `defaults.js`)
2. `python build.py` → ได้ `public/index.html`, `index.html`, `dist/TET-กราฟรายงาน.html`
3. commit + push

## ไฟล์ที่อ่านได้
| ไฟล์ | ใช้คอลัมน์ | ได้ค่า |
|---|---|---|
| `dd.mm.yyyy สรุป.xlsx` (เปิดบิลสั่งย้อม) | วันที่, เลขที่บิล, นิ้วอบ, เฉด, น้ำหนัก | ขาว/ดำ/ล้างน้ำ/สี, แคบ/กว้าง/ผ่า/รออบ, ผ้าซ่อม/ตีกลับ |
| `ค้างส่ง dd.mm.yyyy.xlsx` | วันที่ขนส่งรับ, น้ำหนักสุทธิ | ผ้าค้างส่ง, ค้างเดือนก่อน (ขนส่งรับก่อนต้นเดือน), ค้างหลัง 8 โมง (ขนส่งรับตั้งแต่ 08:00 ของวันรายงาน) |
| `สรุปปี2026.xlsx` | ชีต `YYYY.MM` | นำเข้าย้อนหลังทั้งเดือน + เป้า + วันหยุด |

กรอกมือ: ส่งผ้าซ่อม, ส่งผ้าดี, รับผ้าจากผลิต (ไม่รวม C), รับผ้าดิบเข้าโรงงาน

## กติกาคำนวณ (ตาม Excel เดิม)
- ประเภทบิลดูจากตัวอักษรนำหน้าเลขที่บิล (ตรวจแบบยาวก่อน เช่น BC ก่อน B) — ไม่ตรงแถวไหน = ออเดอร์
- นับเฉพาะบิลออเดอร์ในขาว/ดำ/ล้างน้ำ/สี และแคบ/กว้าง/ผ่า/รออบ (นิ้วอบที่ไม่มีในตาราง = รออบ)
- ค่าเฉลี่ย = เฉลี่ยเฉพาะวันที่มีข้อมูล · สะสม = ยอดจริงสะสม (วันหยุดค้างค่าเดิม)
- เป้าสะสมเพิ่มเฉพาะวันทำงาน (ค่าเริ่มต้น: อาทิตย์หยุด) · เป้าเดือน = เป้าต่อวัน × วันทำงาน (แก้ทับได้)

## เปลี่ยนไปเก็บข้อมูลกลาง (Supabase/Firebase) ภายหลัง
แก้ object `Storage` ใน `src/app.js` (ส่วนที่ 2) ให้ `load()/save()` อ่าน-เขียนจาก server แทน localStorage
